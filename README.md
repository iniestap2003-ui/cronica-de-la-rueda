# Crónica de la Rueda

Los catorce libros de *La Rueda del Tiempo* resumidos en un libro que se hojea, con un mapa en relieve de personajes y ejércitos libro a libro. Los libros que aún no has leído van sellados.

Es una aplicación web instalable: ábrela en el móvil y añádela a la pantalla de inicio. Funciona sin conexión.
